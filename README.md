## ✨ Features
 
- 🎨 **Glassmorphism UI** — Modern frosted glass card design
- 🌌 **Animated Particle Canvas** — Interactive background with connecting lines
- ⌨️ **Typing Animation** — Dynamic role switcher in the hero section
- 📱 **Fully Responsive** — Works seamlessly on mobile, tablet, and desktop
- 🖱️ **Custom Cursor Glow** — Soft glow effect that follows the mouse
- 🔢 **Animated Counters** — Stats that count up on scroll
- 📊 **Skill Progress Bars** — Animated bars triggered on viewport entry
- 🃏 **3D Tilt Effect** — Project cards with perspective tilt on hover
- 📜 **Smooth Scroll** — Buttery smooth navigation between sections
- 🍔 **Mobile Menu** — Animated hamburger menu for smaller screens
- 📄 **Resume Download** — One-click CV download built right in
- ✅ **Contact Form** — Validated message form with toast notifications

## 🚀 Getting Started
 
### Clone the repository
 
```bash
git clone https://github.com/Jayantaddi2026/portfolio-website.git
cd portfolio-website
```
 
### Run locally
 
No build tools needed! Just open `index.html` in your browser:
 
```bash
# Option 1 — Double click index.html
# Option 2 — Use VS Code Live Server extension
# Option 3 — Python simple server
python -m http.server 5500
```
 
Then visit: `http://localhost:5500`
